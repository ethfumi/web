# THREE BODIES

3 つの星が重力で引き合う軌道を、ブラウザでリアルタイムに計算して描く三体問題シミュレーター。

## 収録軌道

| グループ | 軌道 |
|---|---|
| PERIODIC | 8 の字解（Moore 1993、Chenciner–Montgomery 2000）と、Šuvakov–Dmitrašinović 2013 の周期解 15 個（Butterfly I–IV、Moth I–III、Yin-Yang I・I B・II A・II B、Yarn、Bumblebee、Goggles、Dragonfly） |
| CLASSIC | ラグランジュの正三角形解、オイラーの直線解、Burrau のピタゴラス問題（質量 3・4・5） |
| SOLAR SYSTEM | 恒星・惑星・月、連星のまわりの惑星、トロヤ群（L4 のおたまじゃくし軌道）、馬蹄形軌道、スイングバイ、実際の太陽系（太陽〜木星の 6 体、木星〜海王星の 5 体） |
| CHAOS | 連星と来訪者の交換反応、束縛されたランダムな 3 体（選び直すたびに seed が変わる） |

数字キー 1–0 は、8 の字・Butterfly I・Moth I・Yin-Yang I・Yarn・ラグランジュ・ピタゴラス・恒星惑星月・連星の惑星・ランダムに割り当ててある。

## 操作

- ドラッグ: 視点の移動 / ピンチ・マウスホイール: ズーム（操作すると AUTO CAMERA が切れる）
- SPACE: 再生・停止 / 1–0: 軌道の選択 / N・B: 次・前 / R: やり直し / G: 分身 / F: 回転座標 / E: 編集
- SPEED / TRAIL: 進む速さと軌跡の長さ（軌道ごとの既定値に対する倍率）
- INTEGRATOR: 積分法の切り替え。EULER にするとエネルギーが増え続けて軌道が膨らむのが見える
- EDIT: 星をつまんで位置を、矢印の先をつまんで速度を変える。質量はスライダーで 10⁻³〜10。
  変えた時点の状態が新しい初期条件になり、時刻とエネルギーの基準を取り直す
- GHOST: 分身の系を並走させ、本体との最大のずれを `GHOST Δ` と左下の対数グラフに出す。
  - `10⁻⁶`: 星 1 の位置を 10⁻⁶ だけずらした分身。安定な軌道ではほとんど開かず、カオスな軌道では指数的に開く
  - `METHOD`: 同じ初期値を別の積分法で計算した分身。積分法どうしの差が見える
- ROTATING FRAME: 点線で結んだ 2 体と一緒に回る視点。惑星が止まって見え、ほかの星の「惑星から見た動き」だけが残る。
  基準はトロヤ群と馬蹄形軌道では恒星と惑星、太陽系の内側では太陽と地球（火星の逆行が見える）、ほかは質量の大きい 2 体。
  物理は慣性系のままで、回すのは表示・軌跡・背景の星空だけ
- LABELS: 太陽系や階層系の星に名前を出す
- 上部の `ΔE` は、開始時の全エネルギーからの相対的なずれ。0.1% を超えると注意書きを出す

## 仕組み

- `physics.js`: 物理。質点、G = 1、倍精度。星の数は任意で、画面側は 12 個まで。
  太陽系は太陽質量・天文単位の単位系で、1 年 = 2π。惑星の質量・長半径・離心率は実際の値、出発の向きは適当。積分法は Euler / RK4 / Leapfrog / Forest-Ruth（4 次シンプレクティック、既定）。
  時間刻みは可変で、いちばん近いペアの自由落下時間 `sqrt(r³ / (mᵢ + mⱼ))` の 0.5%（接近遭遇が深い軌道は 0.2%）。
  ソフトニングは入れていない。
- `app.js`: 描画と操作。WebGL2 + GLSL ES 3.00、外部ライブラリなし。
  背景（星空・重力ポテンシャルの等高線・星の光）は全画面の fragment shader 1 枚、軌跡は CPU 側に持った点列をインスタンス描画する。
  分身のグラフと編集用の矢印は、上に重ねた 2D canvas に描く。

## 精度について

- 周期解の初期値は文献の 5〜8 桁の値。8 の字以外は不安定なので、数周すると丸めの分だけ軌道がほどけていく。
- 可変の時間刻みを使うと、シンプレクティック法でもエネルギー誤差が完全には有界にならない。
  8 の字を 1000 周させた相対誤差は Forest-Ruth が 5×10⁻⁹、RK4 が 2×10⁻⁹。
  刻みがほぼ一定になる階層的な軌道では Forest-Ruth の誤差は増えず、連星の惑星を T = 10000 まで回して 10⁻¹³、RK4 は 10⁻⁹。
- ピタゴラス問題は接近遭遇が深く、刻みを粗くすると星が弾き出される時刻が変わる。
- 星どうしが 10⁻⁶ より近づく正面衝突では、時間刻みが下限（10⁻¹²）に張りついて誤差が出る。
- オイラーの直線解は、完全に対称な初期値だと丸め誤差も対称に入って崩れない。中央の星を 10⁻⁹ ずらしてある。

## 開発

```powershell
python -m http.server 8645 --directory three-body
node --test three-body/test/physics.test.js
```

テストは、周期解が 1 周で出発点へ戻ること、エネルギーと運動量の保存、ピタゴラス問題の弾き出し、
トロヤ群と馬蹄形軌道の往復範囲、スイングバイ前後の軌道長半径、交換反応の結果を確かめる。
