# THREE BODIES

3 つの星が重力で引き合う軌道を、ブラウザでリアルタイムに計算して描く三体問題シミュレーター。

## 収録軌道

| キー | 名前 | 内容 |
|---|---|---|
| 1 | FIGURE-8 | 8 の字解（Moore 1993、Chenciner–Montgomery 2000） |
| 2 | BUTTERFLY I | Šuvakov–Dmitrašinović 2013 の周期解 |
| 3 | MOTH I | 同上 |
| 4 | YIN-YANG I | 同上 |
| 5 | YARN | 同上 |
| 6 | LAGRANGE | 正三角形解。等質量では不安定で、丸め誤差から崩れる |
| 7 | PYTHAGOREAN | Burrau のピタゴラス問題（質量 3・4・5、静止から開始） |
| 8 | STAR·PLANET·MOON | 恒星・惑星・月の階層系 |
| 9 | CIRCUMBINARY | 連星のまわりを回る惑星 |
| 0 | RANDOM | 束縛されたランダムな 3 体。選び直すたびに seed が変わる |

## 操作

- ドラッグ: 視点の移動 / ピンチ・マウスホイール: ズーム（操作すると AUTO CAMERA が切れる）
- SPACE: 再生・停止 / 1–0: 軌道の選択 / N・B: 次・前 / R: やり直し / G: 分身
- SPEED / TRAIL: 進む速さと軌跡の長さ（軌道ごとの既定値に対する倍率）
- INTEGRATOR: 積分法の切り替え。EULER にするとエネルギーが増え続けて軌道が膨らむのが見える
- GHOST: 星 1 の位置を 10⁻⁶ だけずらした分身の系を並走させ、本体との最大のずれを `GHOST Δ` に出す。
  安定な軌道ではほとんど開かず、カオスな軌道では指数的に開く
- 上部の `ΔE` は、開始時の全エネルギーからの相対的なずれ

## 仕組み

- `physics.js`: 物理。質点、G = 1、倍精度。積分法は Euler / RK4 / Leapfrog / Forest-Ruth（4 次シンプレクティック、既定）。
  時間刻みは可変で、いちばん近いペアの自由落下時間 `sqrt(r³ / (mᵢ + mⱼ))` の 0.5%（ピタゴラス問題は 0.2%）。
  ソフトニングは入れていない。
- `app.js`: 描画と操作。WebGL2 + GLSL ES 3.00、外部ライブラリなし。
  背景（星空・重力ポテンシャルの等高線・星の光）は全画面の fragment shader 1 枚、軌跡は CPU 側に持った点列をインスタンス描画する。

## 精度について

- 周期解の初期値は文献の 5〜8 桁の値。8 の字以外は不安定なので、数周すると丸めの分だけ軌道がほどけていく。
- 可変の時間刻みを使うと、シンプレクティック法でもエネルギー誤差が完全には有界にならない。
  既定の設定で、周期解 1 周あたりの相対誤差は 10⁻⁸ 未満（8 の字は 10⁻¹¹ 程度）。
- ピタゴラス問題は接近遭遇が深く、刻みを粗くすると星が弾き出される時刻が変わる。

## 開発

```powershell
python -m http.server 8645 --directory three-body
node --test three-body/test/physics.test.js
```

テストは、周期解が 1 周で出発点へ戻ること、エネルギーと運動量の保存、ピタゴラス問題の弾き出し、階層系の安定を確かめる。
