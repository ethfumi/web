# train-go — つなげて！でんしゃ！

3歳児向けのでんしゃアプリ (PWA)。iPad の Safari で開き「ホーム画面に追加」して全画面で遊ぶ。

## 設計原則

- 文字が読めなくても遊べる(タップとスワイプのみ)
- 失敗・ゲームオーバーがない(何をしても楽しい反応が返る)
- 操作したら即座に音と動きで反応する
- 知育要素はでんしゃの文脈に自然に混ぜる(v1 は連結による数の数え上げ)

## 遊び方

路線と車両は地方別に加えて47都道府県でも絞り込める。県名の表示は漢字・ひらがな設定に連動する。鉄道は駅、空路・航路は発着地のある県が対象で、複数県にまたがる路線はそれぞれの県から探せる。

1. まず路線・空路・航路を選ぶ。路線と車両の候補は最初から全件並び、検索と地域・種類で絞り込める。車体の絵だけ画面付近で描き、遠くの絵は解放する。乗り物の選択画面はその路線のおすすめを最上段に表示し、最近の車両、その他の車両と続く。「はやぶさ」「みずほ」などの列車名も車両検索の別名として使え、表示名は形式名・説明のままにする。最近選んだ路線と車両は各10件まで端末へ保存。コース・出発方向は「いきさき・はしるむきを えらぶ」で開く。空路では空の乗り物、航路では船だけが表示される。
2. 車両を選ぶと行き先・次駅を車内放送風に案内する。終点では「次は、終点、終点、みたかです」、回送では「どなた様も、ご乗車になれません」と状況に合わせて言い分ける。画面タップで発車(警笛)、連打で加速。
3. 画面下部の車両アイコン＋で直接連結。「えらぶ」から全車両を検索して連結でき、その車両は次から左側の追加欄にも並ぶ。候補は最大9件を保存し、小画面では横へスクロールできる。出発時の車両は常に右端、🚃−の直上へ固定する。選択画面を開いている間は走行を一時停止し、閉じると続行する。🚃−で最後の車両から切り離す。読み上げは編成両数のみで、最大100両。
   横からは編成が長くなるとカメラが自動で引き、100両まで全車両が画面に収まる。「うえから」はカメラ・ズームとも最初から手動で、開いた列車の位置と縮尺を保ち、指で周りを眺められる。「カメラ じどう」「ズーム じどう」でそれぞれ自動へ戻せる。
4. 路線の駅順・ゲーム内距離を走ると駅が来て自動でブレーキ、ぴったり停車。山手線は一周し、ほかの路線は終点で折り返して途中駅を逆順に戻る。復路では編成が左を向き、駅・線路・町並み・雲が往路と反対向きへ流れる。中央線は東京駅から高尾駅まで走る。京王線は出発前に橋本方面／京王八王子方面を選べる。出発前から開始駅のホームと複数の駅名板が見える。ホームは地形としてそのまま流れ、ホーム先端を先頭車両の停止位置として、長さにかかわらず編成を横へ補正移動せずに停車する。東海道は16両、東北は17両が収まる長さを最低基準にし、各在来線も標準編成が収まる。大ターミナル・主要駅・街の駅・小さな駅で、屋根や設備の豪華さが変わる
5. 駅では「ドアをあける」を押すと、いろいろな人や動物がランダムに乗り降りする。もう一度押してドアを閉める
6. 画面をタップして次の駅へ出発。ドア操作も画面タップで進められる
7. 左上に現在速度、m単位で増え続ける総走行距離(kmは小数第1位で併記)、次の駅までと終点までの残り距離を表示。線路脇には100m間隔の距離標が流れる。最初のタップでしっかり発進し、その後は上限なくタップを重ねるたび速くなる
8. 路線に合わせて、中央特快・新幹線の特急・東西線快速・井の頭線急行・京王線特急の停車パターンへ切り替えられる。速達運転中はスタンプ帳で停車駅と通過駅を確認できる。さらに回送へ切り替えると、終点と未連結時の盛岡だけに停車し、すべての途中駅を通過する。急行設定のない路線でも回送は選べる。総武線は三鷹〜千葉の各駅停車として遊ぶ。「走行音」で音のON/OFFを切り替えられる
9. 「じどう」を押すと、路線ごとの実際の速度を目安に自動加速し、到着案内・ドア開閉・乗降・発車案内・次駅への発車まで自動で進む。自動運転中も画面タップで一時的に加速でき、もう一度押せばいつでも手動へ戻せる

### 地図・国際線

鉄道655コースは国土数値情報などの線路形状を使い、駅間も実際のカーブに沿って描く。列車もその線に沿って移動する。描画密度は道路と同程度に簡略化し、停車駅・ゲーム内距離は維持する。[形状の出典と精度](data/rail-shapes.md)。

地図には近隣の国・地域名と主要都市名を表示し、「🌐 こくさいせん」から代表的な国際空路11本・航路4本を選べる。国・都市名でも検索可能。旅客休止・休止予定の船2本は参考線で表示する。[出典・収録範囲](data/international-network.md)。

地図を指で動かして離すと、短い慣性で滑らかに減速する。触り直し・ピンチ・カメラやズームの切替で慣性は止まる。一覧のスクロールはブラウザ標準の慣性を利用する。

### くるまモード

「🚗 くるま」から道路を選び、軽自動車・コンパクトカー・セダン・SUV・ミニバン・バス・トラックでドライブできる。
消防車・パトカー・ショベルカー・ダンプカー・救急車・ごみ収集車・ミキサー車・クレーン車も加えた全15種類。はしご・バケット・ドラムなど、車ごとの形を選択画面と走行画面で描く。
道路名・番号・都道府県で探し、出発方向も選べる。横からは道路と車、上からは道路形状に沿う車を表示する。
鉄道・空路・航路・道路は個別に表示を切り替えられ、開始時は遊んでいる種類だけを表示する。
タップ加速・自動運転・折り返しに対応し、車には連結や鉄道の運賃を適用しない。
高速道路等は100km/h、一般道は60km/hを自動運転のゲーム用目安とする。実際の制限速度・料金・一方通行を案内するナビではない。
道路は元データの接続を保った簡略コース。海上区間・階段・未開通区間を直線でつながず、途切れた部分は別コースにする。[収録範囲と加工方法](data/roads.md)。

### ひこうきモード

羽田発の幹線（いたみ・新千歳・那覇・福岡・小松・八丈島）、那覇発の離島（石垣・宮古）、
鹿児島発（屋久島・奄美）、成田発の国際線（ホノルル・グアム）など、複数の空路を選べる。
大阪方面は実在の伊丹空港（大阪国際空港）へ飛ぶ。横からは離陸・巡航・着陸する飛行機と空港を描き、
「うえから」では飛行機を追い、「ぜんたい」では地図上の空路全体を見る。飛行機では鉄道専用の
連結・ドア・ライト・種別操作を隠し、パイロットごっこ・自動操縦・タップ加速・スタンプ・乗客を使える。
最初のタップで250 km/hまで加速し、その後はタップごとに＋50 km/h。手動操縦中は自然減速せず、速度と飛行区間に合わせて高度が変わる。途中ではジェット気流に乗ると＋180 km/h加速する。飛行中はやわらかいジェット音が鳴る。
2025年の国内旅客実績がある272組（87空港・ヘリポート）と既存の国際線2組を収録する。離島のヘリコプター5組も選べる。空港名・島名で検索し、どちらの空港からも出発できる。
空路と地図はすべて事前収録し、プレイ中の通信は行わない。実際の当日ダイヤではなく、空港間を移動するゲーム用コース。[出典・範囲・運賃の扱い](data/transport-network.md)を参照。

### フェリーモード

宮島口⇄宮島、鹿児島⇄桜島、青森⇄函館、東京湾（久里浜⇄金谷）、小笠原（東京⇄父島）、
太平洋フェリー（名古屋⇄苫小牧）、新日本海フェリー（敦賀⇄小樽）などを選べる。
横からは海と港・船を描き、鉄道専用の連結操作は隠す。船長ごっこ・自動運航・タップ加速・スタンプ・乗客に対応する。
出航はゆっくりで、空路より低い速度で港まで進む。海路データは事前収録で、プレイ中の通信は行わない。

船は全国の港間を整理した594コース。島名・港名・航路名で検索でき、出港方向を選べる。港名を照合できない線も薄い灰青色の参考線として地図に残すが、選択コースにはしない。現役の全航路・全島の完全網羅を保証するものではなく、収録資料・除外・未確認箇所は[航路の収録範囲](data/transport-network.md)に記載する。

### ぜんこくのてつどう

北海道から沖縄まで、全47都道府県のJR・私鉄・地下鉄・路面電車・モノレール・新交通・ケーブルカーを選べる。
鉄道は支線・直通コースを含む655コース。地域ボタンと路線名・駅名の検索（漢字・ひらがな・カタカナ）で絞り込み、始発・終点の表示で同名路線の区間も見分けられる。
鶴見線・成田線・函館本線などの支線は別コースとして選択でき、札幌市電・名城線などの環状線は一周する。
既存のスタンプ記録を引き継ぎ、追加分も地図・自動運転・折り返し・オフラインに対応。
車両選択の画像は見えている分だけ描画し、全国分の画像を同時にメモリへ載せない。

路線を選ぶと、車両選択画面の上で行き先と出発方向を指定できる。京王線は京王八王子／橋本方面を事前指定し、ランダム分岐は行わない。
三鷹〜千葉を千葉発にするなど、非環状コースは逆方向からも遊べる。最近選んだコースの出発方向も保存する。
「ちょくつう」からは沼津〜宇都宮、中央林間〜南栗橋、西武秩父〜元町・中華街など[9つの長距離コース](data/through-services.md)を選べる。
これらは直通する路線の接続を題材にした各駅停車のゲーム用コースで、実際の列車ダイヤの再現ではない。
路線名・駅名の表示はひらがなが初期設定。選択画面と地図表示中の「あ／漢」から漢字へ切り替えられ、設定を端末に保存する。横からの景色では文字切替ボタンを表示しない。読み上げとスタンプの保存キーは読みのまま維持する。
地図では鉄道・空路・航路を個別にON/OFFできる。開始時は今乗っている種類だけON。走行中のコースを含むその種類の線・駅表示を切り替え、列車・飛行機・船の現在位置は表示し続ける。

収録基準は station_database v20260831 の現役扱い602レコード（旧社名の重複4件を統合した598レコード）と、補完したケーブルカー18路線。
季節営業や運休中の存続路線を含む。貨物専用線・廃線・索道・園内遊具は対象外。
追加分の距離・線形・車両はゲーム向けの近似。[出典・収録範囲・再生成手順](data/README.md)を参照。

東海道・山陽・九州・西九州・東北・北海道・秋田・山形・上越・北陸の10路線を選べる。
つくばエクスプレスは秋葉原からつくばまでの20駅を走り、快速運転も楽しめる。
周辺路線として、上野から取手までの常磐線と、浅草から東武動物公園までの東武スカイツリーラインも選べる。
千代田線直通の常磐線各駅停車は代々木上原から取手まで走り、亀有・金町・北松戸・馬橋・新松戸・南柏も通る。
関東の路線として、東神奈川〜八王子の横浜線、川崎〜立川の南武線、府中本町〜西船橋の武蔵野線、茅ケ崎〜橋本の相模線を選べる。

既存の「うえのとうきょうライン」「しょうなんしんじゅくライン」が担当するため、正式区間だけを収録している。
ニューシャトル（埼玉新都市交通伊奈線）は大宮から内宿までの13駅・12.7kmを走る。

大阪メトロ中央線は長田から夢洲までの15駅を走り、夢洲到着時には海と未来をイメージした特別演出を表示する。
駅順・距離・地図座標は事前収録し、追加通信なしで走行・地図表示・折り返しに対応する。

### 走行中のおたのしみ

- 東海道新幹線でしろいしんかんせんに乗ると、実際の見え方に近い「みしま〜しんふじ」区間で富士山が見える
- 東海道新幹線できいろいけんさしゃに乗ると、最初の区間で線路検査の光とキラキラが見える
- 京王多摩センターでは虹・星・風船の「ゆめいっぱいのまち」演出と特別スタンプが出る。既存のキャラクター・ロゴ・楽曲は使わない
- 高尾の山、千葉の空中モノレール、葛西の地下鉄博物館、吉祥寺の公園、上野の動物も駅ごとの特別演出とスタンプで登場する
- 実際に地下・トンネルを通る駅間だけ、コンクリートの壁・アーチ・照明が流れる。京王線は地下2階ホームの新宿駅から地下風景で始まる。井の頭線は神泉駅を地下のまま描き、神泉〜駒場東大前で地下と地上をなめらかに切り替える。往路と復路の両方に対応。大きな「ライトをつける」ボタンで前を照らせる
- 車両には先頭から順番に番号がつき、増やした編成の最後は後尾車になる
- 新幹線と通勤電車を好きな順番で混ぜて連結できる。色だけでなく種別ごとに形も変える。
  新幹線は流線形のロングノーズ・ドア1つ・低いパンタグラフ、通勤電車は切妻の箱型・4扉・貫通扉のある
  運転台・屋根上のクーラーとパンタグラフ、新交通システム（ニューシャトル）は小さく低い丸い車体・2扉・
  平らな屋根・ゴムタイヤで描き分ける。車両えらびの絵も同じ描き分けに合わせる
- 走行途中の車内アナウンス、ドア開閉音、速度に連動してiPadでも聞こえやすい走行音が鳴る
- 最初のタップは＋30 km/hで発進し、その後はタップごとに＋5 km/h加速する。乗客を目的地へ1人送り届けるたび、そのプレイ中のタップ加速が＋1 km/h育つ。黄色・緑・青・虹の星が有効な間は、育った加速量が2・4・6・10倍になる。実際に増えた値が速度計のそばに浮かび、車体の後ろには加速線が出る。駅手前の自動ブレーキ中は加速表示を出さず、車輪にブレーキの光が出る
- 走行中に色の違う流れ星が斜めに落ちてくる。黄色は2倍・5秒、緑は4倍・6秒、青は6倍・7秒、超レアな虹は10倍・8秒のタップ加速。「うえから」「ぜんたい」では線路の近くに丸い加速パワーとして表示する。黄色、緑、青、虹の順に小さく速くなり、レアなほど長いほうき星のような尾を引く。残り時間も表示する。昼の抽選口数は70・20・9・1で、夕方と夜は黄色だけ40、20へ減る。青か虹を逃すたび、その星の抽選口数が基礎値ずつ増え、取ると元へ戻る
- 向こう側の線路には、その路線や並走区間に合う電車が現実に近い頻度と編成両数で反対向きに通過する。自分が速いほど双方の速度を足した相対速度ですばやく流れ、列車をタップすると両数を読み上げる。新幹線は編成の両端を流線形の先頭車両にし、在来線は両端に運転台、貨物列車は先頭に機関車を描く。東海道新幹線は16両、みどりのしんかんせんは10両、あかいしんかんせんは7両、連結列車は17両、貨物列車は26両で登場する
- 乗客には行き先があり、目的の駅で降りる。右上は人のアイコンと人数を小さく表示し、タップした時だけ「だれが・どこへ」を確認できる
- 走るほど昼・夕焼け・夜と、晴れ・雨・雪が切り替わる。夜は前照灯が自動点灯し、客室の窓も暖かく光る
- 駅間では次の駅へ近づくにつれて、建物の高さ・密度や屋根・木が徐々に変わり、街並みが自然につながる
- 走行中、ときどき地形として踏切が現れる。近づくと高く大きく、通過後は低く小さくなる警報音で距離感を楽しめる
- 「うんてんし」ボタンで「信号よし」「ドアよし」などの指差し確認ごっこができる
- 駅に到着するとスタンプを集める。スタンプ帳は端末へ自動保存され、リロード後も続きから集められる
- 右上の時計に、列車を選んでから遊んだ時間を分・秒で表示する。ホームへ戻って列車を選び直すと0分0秒から始まる
- スマートフォンの縦長画面では、走行操作・ドア操作・車両追加を分けて配置し、下部のボタン同士が重ならない。線路と地面も上へ配置し、うんてんし・スタンプボタンが車両へ重ならない
- みどりのしんかんせんは白い車体、青緑の上部、ピンクの帯で表示する

## 技術

- 素の HTML / CSS / JSでcanvas描画。配布時だけ `python train-go/tools/build-runtime.py --optimize` でコードとデータをgzipへまとめ、起動時に展開する
- 音声: Web Speech API (読み上げ) + WebAudio (警笛・チャイム)。外部素材なし
- PWA: manifest + service worker (https または localhost で登録、オフライン可)
- 車両選択画面の下に、反映確認用のバージョンと更新日時を表示。更新時は index.html と sw.js のバージョンを揃える
- 路線選択画面に、端末内へ保存した全路線・空路の累計移動距離を小数点以下2桁のマイルで大きく、kmで小さく表示する
- 乗客を目的地まで届けると運賃が加算され、トップで累計金額を表示する（使い道は未実装）。運賃は距離帯テーブルの近似
- 京浜東北線・京葉線（舞浜）・ゆりかもめ・りんかい線・横須賀線・内房線を選べる。飛行機でも乗客が乗り降りする
- Xなどで共有した時にタイトル・説明・アイコンを表示するOGPと、作者・感想・不具合の連絡先リンクを車両選択画面に表示する
- アイコン生成: `python make_icons.py` (要 Pillow)
- 全路線で、編成全体を真上から追う「うえから」と、路線全体を見る「ぜんたい」、通常の「よこから」を切り替えられる。地図は北を上にして縦横比を維持し、「うえから」はカメラ・ズームとも手動で開始し、自動ズームへ切り替えると1〜100両が収まるように調整する。地図表示中も速度計・種別・走行音・自動運転・車両追加・運転士・スタンプなどの操作を残し、地図では使わないライト操作と大きなイベント表示だけを隠す。地図上では、動かさない複数の指をそれぞれ加速タップとして数え、指の間隔を変えた時だけピンチズームに切り替える。周辺の路線も簡略線で表示し、中央線と総武線など重なる区間はごく少しずらして並走させる。画面に重なる路線は縮尺によらず必ず描き、画面から遠いものだけ本数上限で省く。非表示にした交通種別は周辺路線の探索対象から外す。地図の文字は重ならないように配置し、混んだ場所では駅名、路線名、ランドマーク名の順に優先する。走っている駅と次の駅の名前はいちばん先に置く。置けなかった駅名は左右や離れた位置でも再配置し、表示を増やす。同じ系統の京王本線と相模原線は共通区間を重ねる。日本の輪郭、琵琶湖などの湖、流れをたどれる簡略線を主体とした川、島名・山頂名と標高、約2km間隔の標高の色分け、道路・建物・公園も描き、地図表示中は通常風景と対向列車の更新を止める。地図は事前収録され、プレイ中の通信は行わない。地図データ: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) / ODbL 1.0。海岸線: [Natural Earth](https://www.naturalearthdata.com/) 1:10m（周辺地域を簡略化） / public domain。関東の追加路線データは [station_database](https://github.com/Seo-4d696b75/station_database) v20260731（CC BY 4.0）を基にし、駅座標間の測地距離をゲーム内キロへ累積している

## 動作確認 (ローカル)

地図の「げんざいち」は、押した時だけブラウザへ位置情報を要求し、取得した場所を青い点で表示する。位置へ移動するとカメラとズームは手動になる。座標をアプリから外部送信・永続保存せず、追跡も行わない。許可拒否・タイムアウト・非対応時は案内を表示する。GPS等の実際の測位方法・精度は端末とブラウザによる。

```
python -m http.server 8642 --directory train-go
```

`http://localhost:8642/?debug` で開くと `window.__tg` にデバッグフックが生える
(`__tg.skipToStation()` で駅直前までワープ、`__tg.status()` で内部状態、
`__tg.profile()` で描画段階ごとの平均所要時間 ms/フレーム。呼ぶたびに集計をリセットする)。
地図表示中は canvas の `data-map-scale` / `data-map-related-lines` / `data-map-related-dropped` に
縮尺と周辺路線の描画状況が出る。`?debug&keio=hashimoto` / `?debug&keio=hachioji` で京王線の行き先を固定できる。

## 既知の挙動

- 地図の背景・街・路線・固定ラベルは列車とは別のcanvasへまとめてキャッシュする。静止中は大きな背景画像を毎フレーム転写せず、ブラウザが保持するレイヤーの上で列車だけを描き直す。
- 追従表示では画面外に余白を持ち、移動中は画像を平行移動する。余白の端、縮尺・モード・路線・現在駅/次駅・昼夜・画面サイズ・DPR・フォントの変更で再生成する。
- 地図モードだけ DPR を `MAP_DPR_CAP`（既定1.5）以下に抑え、文字幅とラベル配置も再利用する。再生成は1フレームに最大1枚。
- 駅名の衝突判定は64pxの区画で近傍だけを調べ、表示するラベルと優先順を維持する。
- 「うえから」でも海・湖を塗り分ける。国土地理院の水域データを全国の鉄道沿線へ追加し、東京湾の港湾・埋立地も補完する。
- 路線数・街ブロック数・ラベルの縮尺による間引きは行わず、画面外の除外とラベル衝突回避だけを残す。遠景の街は点の LOD で表示する。
- `?debug` の `__tg.profile()` で `map:cache-rebuild` を確認でき、`canvas.dataset.mapCacheRebuilds` / `mapRelatedDropped` / `mapTownBlocks` に再生成回数・省略路線数・街の描画数を出す。
- タブ/アプリが非表示の間は 200ms 間隔の低頻度更新に落ちる(電池対策と検証容易性の折衷)
- 走行中の数値表示は毎秒10回に抑え、100両編成でも描画ごとの一時オブジェクトを増やさない
- 基本データは `train-route-data.js`、既存の追加分は `national-rail-route-data.js` と `kanto-rail-route-data.js`。全国版の `all-rail-route-data.js` が路線を補完・更新する。空路は `air-route-data.js`、地図は `map-data.js` に分離し、`app.js` はゲーム処理を担当する
- 読み上げの声質は端末の Web Speech API に依存する
- オンライン時は HTTP cache を避けて最新版を取得し、取得成功時にオフライン用Cache Storageを更新する
- 新しい service worker が有効になった時は一度だけ自動リロードする
