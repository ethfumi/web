# 道路と車モード

## 出典と収録方法

[OpenStreetMap contributors](https://www.openstreetmap.org/copyright)（ODbL 1.0）の道路を2026年9月23日に取得・加工。
一般国道459番号、高速道路・自動車専用道路等、地方の幹線50本、東京の通り12本を対象とする。
v136は国道459本、高速道路等325本、地方50本、東京12本の計846本・1,377コース。ゲーム起動用ファイルは合計2,815,823バイト（v135比+433,589バイト）。
高速道路の候補は日本付近の `highway=motorway` を含む道路リレーションから抽出する。法令上の路線数や営業中の全IC・全ランプを保証する一覧ではない。
東京では環七・環八・山手・明治・内堀・外堀・目白通り、青梅・新青梅・五日市街道、井の頭通り、東八道路を道路名から抽出する。
道路番号・呼称の重複や上下線を整理し、形状と出典IDを `road-network.json`、取得対象を `road-sources.json` に保存する。

## ゲーム内のコース

- 元のOSMノードIDが共通する道路だけを接続し、各連続区間の代表経路をコースにする。全ての車線・側道・枝道を走破する経路ではない。
- 立体交差は座標が交差するだけでは接続しない。海上区間、階段、歩行者・自転車専用道、工事・計画区間、私道などは除外する。
- 元データの欠落で途切れた区間も別コースにする。近くに見える端点を推測でつながないため、現実には連続する道路が複数コースに分かれる場合がある。
- 約35m相当で形状を簡略化し、座標を小数4桁の整数差分へ圧縮する。距離はこの形状から計算したゲーム内の近似値。
- 発着地点は近くの交差点等の名称、近隣の駅名、または方角で示す。「付近」はその施設に直接乗り入れる意味ではない。
- 都道府県は経路上の地点から概略判定する。県境付近の細かな所属を保証する表示ではない。
- 一方通行・交通規制・道路閉鎖・料金・燃料費を再現しない。逆向きも選べる遊び用コースで、実際の運転経路案内には使わない。
- 自家用車・バス・トラック・働く車の15車種は汎用デザイン。バス事業者の路線や運賃ではなく、選んだ道路を同じ操作で走る。

## 再生成

`tools/road-runtime.js` が登録処理の正本。配布用JavaScriptは同梱の加工済みスナップショットから再生成できる。

```sh
python train-go/tools/build-roads.py
python train-go/tools/build-prefectures.py
python train-go/tools/build-runtime.py --optimize
node --test train-go/tests/*.test.cjs
python train-go/tests/road-topology.test.py
```

形状を再加工する場合は `build-roads.py --cache <OSM応答キャッシュ> --inventory <road-sources.json>` を使う。
形状処理にShapely、読み変換にpykakasiを使用する。出典スナップショットと生成ツールはゲーム起動時に配信・キャッシュしない。
