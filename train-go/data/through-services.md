# 直通コース

直通する路線の接続を題材にしたゲーム用コース。実際の列車ダイヤや停車駅の完全再現ではなく、各区間の収録駅に停車する。
季節・曜日・列車によって運転区間が異なる。ゲーム内距離は駅座標間の測地距離の累積。

| コース | 経由 |
|---|---|
| 沼津〜宇都宮 | 東海道本線・上野東京ライン・宇都宮線 |
| 熱海〜高崎 | 東海道本線・上野東京ライン・高崎線 |
| 逗子〜宇都宮 | 横須賀線・湘南新宿ライン・宇都宮線 |
| 小田原〜高崎 | 東海道本線・湘南新宿ライン・高崎線 |
| 中央林間〜久喜 | 田園都市線・半蔵門線・東武伊勢崎線 |
| 中央林間〜南栗橋 | 田園都市線・半蔵門線・東武伊勢崎線・日光線 |
| 小川町〜元町・中華街 | 東武東上線・副都心線・東横線・みなとみらい線 |
| 飯能〜元町・中華街 | 西武池袋線・有楽町線・副都心線・東横線・みなとみらい線 |
| 西武秩父〜元町・中華街 | 西武秩父線・池袋線・有楽町線・副都心線・東横線・みなとみらい線 |

運転区間の参照先（2026-09-22確認）:

- [JR東日本の路線区間案内](https://www.jreast.co.jp/estation/facility_search.aspx?searchCategoryCd=1)
- [JR東日本 上野東京ライン案内](https://media.jreast.co.jp/articles/2938)
- [東武鉄道の路線概要・相互乗入区間](https://www.tobu.co.jp/corporation/rail/route/)
- [東急電鉄 元町・中華街駅の時刻表](https://transfer.navitime.biz/tokyu/pc/diagram/TrainDiagram?rrCd=00001016&stCd=00009364&updown=0)

元データとライセンスは[全国路線データ](README.md)を参照。
`python train-go/tools/build-through-routes.py` で `through-route-data.js` を再生成し、続けて `build-runtime.py` を実行する。
生成時は接続駅の一致と座標の連続性を検査する。
