# 道路・車モードの収録案

## 対象

- 全国の高速道路・一般国道459路線を基本とする。
- 地方の代表的な幹線道路を約50路線選び、東京は追加で手厚く収録する。
- 東京の優先候補は環七、環八、山手通り、明治通り、内堀通り、外堀通り、目白通り、青梅街道、新青梅街道、五日市街道、井の頭通り、東八道路など。甲州街道等と国道の重複は整理する。
- 未開通区間、階段、歩行者専用区間、海上区間などは車用のコースとして接続しない。
- 車両は軽自動車・コンパクトカー・セダン・SUV・ミニバン・バス・トラック等を候補とする。

## 容量の概算

OpenStreetMapの実データで、連続する線を結合し、40m相当で形状を簡略化して整数差分をgzip圧縮したサンプル。名称・コース構成・ゲーム処理は別途必要。

| サンプル | 形状の圧縮サイズ |
|---|---:|
| [国道1号](https://www.openstreetmap.org/relation/32989) | 4,005 bytes |
| [国道20号](https://www.openstreetmap.org/relation/21087) | 1,567 bytes |
| [環七](https://www.openstreetmap.org/relation/2184989) | 732 bytes |
| [環八](https://www.openstreetmap.org/relation/33197) | 543 bytes |

事前概算は約0.3〜0.7MB増、全体約2.7〜3.1MB。v136では上限を3.2MBに変更し、国道459本、高速道路・専用道路等325本、地方の幹線50本、東京の通り12本を収録した。計846本・1,377コース。

起動用ファイルの実測はv135の2,382,234バイトから2,815,823バイトへ増加（+433,589バイト、約434KB）。車モードの処理と7車種も含む。[収録条件と再生成方法](roads.md)を参照。
