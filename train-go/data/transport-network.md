# 空路・航路の収録範囲

## 国内空路

[国土交通省・航空輸送統計調査2025年年報 表3](https://www.e-stat.go.jp/stat-search/files?stat_infid=000040471584)の国内定期路線別表から、年間に旅客輸送実績がある272組を収録する。同じ空港間の往復・複数航空会社を一組とし、貨物専用・旅客実績ゼロの4組は除く。対象は暦年2025年で、2026年9月22日に取得した。

空港・ヘリポートは87か所。伊豆諸島のヘリコプター5組を含む。既存の国内10コースのキーと駅名保存IDを引き継ぎ、262コースを追加する。既存の成田〜ホノルル／グアム2コースも残すため、空路の選択肢は274コース。

座標は[OurAirports](https://ourairports.com/data/)の2026年9月22日取得CSV（Public Domain）から該当する空港コードを対応づけた。日本語名と読みは統計上の名称をもとに整理した。新規コースは空港間の直線と球面距離を使い、実際の航空管制経路は再現しない。既存コースのゲーム内距離は保持する。

これは旅客実績のある空港間を遊ぶための収録一覧であり、今日の運航便・ダイヤを保証するものではない。季節便・その後の休止や新設は年報との時間差がある。

`air-network.json` が加工後の入力。配列の空港要素は `[識別コード, 統計名, 読み, 経度, 緯度, ヘリポートか]`、組は空港配列の添字2つ。

```sh
python train-go/tools/build-air-network.py
python train-go/tools/build-runtime.py
```

## 運賃

全交通種別の運賃はゲーム用の概算。既存の一部空路・航路は固定額、新規空路・航路はそれぞれの距離帯表を使う。
鉄道はJR・地下鉄・私鉄・新幹線の共通テーブルを使い、未分類の新規鉄道はJR幹線の近似となる。会社別の改定、直通時の会社別運賃合算、割引、客室・座席種別、季節料金は網羅しない。実際の旅行費用の見積もりには使わない。

## 全国の航路

2026年9月22日のOpenStreetMapの国内 `route=ferry` をもとに、港名を照合できた隣接港間を590のゲーム用区間へ整理した。往復・並行する同じ港間はまとめ、従来のコースも保存キーを維持する。航路途中の分割点を港と取り違えないよう接続をたどり、途中寄港を含む長い航路は港ごとの区間として選べる。実際にその区間だけ乗船できることや、直行便・乗換・時刻表を保証するものではない。

港名を照合できていない端点が67か所残る。選択用区間として確定しなかった246の線分も、地図では灰青色の参考線として収録する。名称不明の港を創作して選択肢に加えることはしない。これらには遊覧船や古い登録が含まれる可能性があり、現在の運航状況は全件確認できていない。外国航路、判明した廃止航路、遊園地内の船等は除外した。

したがって、全国の全島・全現役航路の完全網羅を保証する一覧ではない。[国交省の旅客船・フェリー事業者一覧](https://www.mlit.go.jp/maritime/bosai_shipslink.html)等も照合に使用したが、統計上の一般旅客定期航路517という事業者単位の集計と、本アプリの港間コース数は比較できない。

主な離島の出発港・到着港は、島名や航路名から検索できる。伊豆・小笠原、利尻・礼文、天売・焼尻、隠岐、瀬戸内、五島、壱岐・対馬、甑島、三島・十島、奄美、南北大東、宮古・八重山などを含む。港に正式名称が登録されていない一部の地点は、出典にある島名に「のりば」を添えて表示し、正式な港名と区別する。

### 出典と加工

- 航路の線・乗り場：[© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)、ODbL 1.0。線を接続し、近接する乗り場を照合してゲーム用区間に加工した。形状は約35mの簡略化、距離は座標からの概算。実航海・ナビゲーションに使用しない。
- 港名照合の補助：国土数値情報（港湾間流通量・海上経路データ）（国土交通省）、[2016年度版](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S10a-2016.html)、2026年9月22日取得。本アプリの開発者が港名と代表点を抽出して加工した。2016年の港の代表点であり、現在の桟橋位置や運航状況を表すものではない。古い航路そのものを現役航路として移植してはいない。
- 国土数値情報の上記データは「商用可」。出典・加工者の表示、権利・時間的／空間的誤差・用途の限界等の継承は[旧国土情報利用約款準拠の利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement_02.html)による。原典著作者の権利が残り、航海・測量・証明などの精度を要する用途には適さない。

加工後の入力は `ferry-source.json`（連絡先等の不要なタグは除去）、個別補正と確認先は `ferry-overrides.json`。`ferry-coverage.json` に除外・名称未照合・各コースの元way IDを記録する。読みは登録値・個別補正を優先し、それ以外はビルド時にpykakasiで変換するため、未確認の読みが残る。

```sh
python -m pip install pykakasi zopfli
python train-go/tools/build-ferry-network.py
python train-go/tools/build-runtime.py --optimize
python train-go/tools/build-runtime.py --check
```
